## Можливості
- Сумісність із підписками Clash, V2ray/V2fly, Sing-box, Shadowsocks, Sub, GitHub Subscriptions.
  - Повна підтримка конфігурації `clash`, часткова підтримка конфігурації `clash.meta`.

- Автоматичний вибір найшвидших вузлів на основі єдиного набору правил маршрутизації для кількох джерел підписок.
- Підтримка власних груп правил маршрутизації та груп вузлів.
  - Налаштовані дефолтні групи правил маршрутизації для початківців — працює одразу «з коробки».
  - Вбудовані набори правил geo-IP, geo-site, ACL та [інші rulesets](https://github.com/KaringX/karing-ruleset/).

- Резервне копіювання та синхронізація: синхронізація кількох пристроїв за допомогою єдиної конфігурації.
  - Підтримка синхронізації через iCloud [iOS/macOS].
  - Підтримка синхронізації в межах локальної мережі.
  - Підтримка WebDAV.
  - Підтримка імпорту/експорту ZIP-файлів.

- Вбудована підтримка [модифікованого ядра sing-box](https://github.com/KaringX/sing-box).
- Впроваджено режим початківця для спрощеного налаштування.
- Планується підтримка більшої кількості платформ.

## Системні вимоги
- Windows >= 10 (тільки 64-бітні версії)
- Android >= 8 (arm64-v8a, armeabi-v7a)
- Linux (тільки 64-бітні версії, glibc >= 2.38 для поточних .deb-пакетів)
- iOS >= 15
- macOS >= 12 (Intel, Apple Silicon)
- tvOS >= 17
